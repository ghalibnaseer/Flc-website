# flcassociates.com

Website of FLC & Associates LLP. Plain HTML and CSS, no build step needed to serve it.

## Pages
- `index.html` The Firm
- `practice.html` Practice areas, services, courts and forums
- `team.html` Team (placeholders marked with square brackets until the team list arrives)
- `ghalib-naseer.html` Full profile, assembled from the portfolio at ghalibnaseer.github.io
- `contact.html` Enquiry form and offices
- `legal-notice.html`, `privacy.html`, `404.html`

Pages are generated by `_tools/build.py` from one source, so the header, footer and office list stay the same everywhere:

    python3 _tools/build.py <path to portfolio clone> .

Folders starting with `_` are not published by GitHub Pages.

## Hosting (free)
1. Firm site: GitHub Pages from this repository (branch `main`, root). Custom domain `flcassociates.com` (the `CNAME` file).
2. DNS stays at Namecheap (Advanced DNS). Add only these records and leave every Google Workspace record (MX, SPF/TXT, DKIM, verification) untouched:
   - A `@` 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
   - CNAME `www` ghalibnaseer.github.io.
   Then tick "Enforce HTTPS" in Settings > Pages once the certificate is issued.
3. Case law database (later): Cloudflare Pages (free) from the private `flc-case-law` repository, with `_tools/database-password-middleware.js` as `functions/_middleware.js`, and a CNAME at Namecheap for the database subdomain pointing to the `.pages.dev` address.

## Contact form
`_tools/contact-form-apps-script.gs` is a Google Apps Script web app in the firm's Google Workspace. Paste its URL into `FORM_ENDPOINT` in `build.py` and rebuild. Until then the form opens the visitor's email program addressed to info@flcassociates.com.
